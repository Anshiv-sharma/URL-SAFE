ABOUT THIS PROJECT

Security, made a little easier to understand.

URL-SAFE is a local-first learning project. It checks four kinds of input against a small set of transparent warning patterns, then explains what those patterns could mean.

The score is a teaching aid, not a verdict. A low score doesn't prove something is safe, and a warning doesn't prove it is malicious. Never paste a real password into a tool you don't trust.
